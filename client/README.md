# Student Grievance Redressal Portal – Frontend

## Overview
This is the **frontend (client-side)** of the Student Grievance Redressal Portal.  
It enables students and authorities to **submit, track, and manage complaints efficiently** through a clean and interactive interface.

Built using **React + Vite** for high performance and fast development.

---

## Tech Stack
- **React (Vite)**
- **JavaScript (ES6+)**
- **CSS (Custom UI Design)**
